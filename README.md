# الديب للمقاولات والاستشارات الهندسية | El Deeb Construction & Engineering

موقع الشركة ومعاه لوحة تحكم، والمحتوى محفوظ في قاعدة بيانات على Vercel.

- 🏗️ **الهيرو مشهد بناء بعرض الشاشة:** مع السكرول بتتبني عمارة سكنية، وبعدها تختفي في الأرض ويطلع برج إداري، وبعده برجين توأم، وفي الآخر برج الديب الرئيسي بالإضاءة والكشافات. الأبراج اللي حوالين كل مبنى بتظهر وتختفي معاه. بعد ما المشهد يخلص بيظهر تحته تعريف الشركة والأزرار.
- 🏢 **صفحة لكل مشروع** فيها التفاصيل ونطاق العمل ومعرض الصور.
- 🧭 **مجالات العمل** بأمثلة لكل مجال.
- 🌐 عربي + إنجليزي، و 🌗 داكن + فاتح.
- 🗄️ **قاعدة بيانات على Vercel:** المحتوى في Upstash Redis والصور في Vercel Blob، وأي حفظ من اللوحة بيظهر للزوار على طول.

## 🚀 الرفع على Vercel (مرة واحدة)

### 1) استيراد المشروع
1. [vercel.com](https://vercel.com) ← **Add New… → Project** ← اختار Repo **Eldeeb** ← **Import**.
2. Framework Preset: **Other**. سيب Build Command و Output Directory فاضيين.
3. **Deploy**.

### 2) ربط قاعدة البيانات (Upstash Redis)
1. من صفحة المشروع على Vercel: **Storage** ← **Create Database** (أو Browse Marketplace) ← اختار **Upstash** ← **Redis**.
2. اختار الخطة المجانية ← **Create** ← **Connect to Project** واختار المشروع (Production و Preview).
3. Vercel هيضيف `KV_REST_API_URL` و `KV_REST_API_TOKEN` لوحده.

### 3) تخزين الصور (Vercel Blob)
1. **Storage** ← **Create Database** ← **Blob** ← **Create** ← **Connect to Project**.
2. Vercel هيضيف `BLOB_READ_WRITE_TOKEN` لوحده.

### 4) كلمة مرور اللوحة
1. **Settings** ← **Environment Variables** ← **Add**:

| الاسم | القيمة |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور قوية للوحة |
| `AUTH_SECRET` | (اختياري) نص عشوائي طويل لتوقيع جلسات الدخول |

2. **Save**.

### 5) إعادة النشر
**Deployments** ← آخر نشر ← **⋯** ← **Redeploy**، عشان المتغيرات الجديدة تتطبق.

بعد كده ادخل `https://اسم-موقعك.vercel.app/admin` بكلمة المرور. أسفل القائمة الجانبية هتلاقي **"متصل بقاعدة البيانات"**.

> أول مرة، المحتوى المعروض هو `data.json`. بعد أول **حفظ ونشر** من اللوحة، الموقع بيقرأ من قاعدة البيانات.

## 🛠 لوحة التحكم

| الجزء | بيعمل إيه |
|---|---|
| ترتيب وإظهار الأقسام | سحب وإفلات + إظهار/إخفاء |
| محتوى الأقسام | الرئيسية، من نحن، مجالات العمل، الخدمات، المشاريع (بمعرض الصور)، التواصل |
| الإعدادات العامة | بيانات التواصل، السوشيال ميديا، محركات البحث |
| معاينة | بتعرض المسودة قبل النشر (كمبيوتر/تابلت/موبايل + عربي/إنجليزي) |
| حفظ ونشر | بيحفظ في قاعدة البيانات ويظهر للزوار فورًا (`Ctrl + S`) |

- التعديلات بتتحفظ كمسودة أول بأول، والزوار مش بيشوفوها غير بعد **حفظ ونشر**.
- الصور بتتضغط وتتحول WebP، وبعدين بتترفع على Vercel Blob.
- جلسة الدخول صالحة 12 ساعة.

**تغيير كلمة المرور:** غيّر `ADMIN_PASSWORD` من إعدادات Vercel واعمل Redeploy.

## 💻 التشغيل على جهازك

```bash
npx serve .
```

من غير قاعدة بيانات، الموقع بيشتغل في **وضع محلي**: التعديلات بتتحفظ في المتصفح، وكلمة مرور اللوحة `admin123`.

للتشغيل مع قاعدة البيانات الحقيقية: `npm i -g vercel` ثم `vercel link` و `vercel env pull` و `vercel dev`.
