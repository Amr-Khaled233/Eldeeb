# الديب للمقاولات والاستشارات الهندسية | El Deeb Construction & Engineering

موقع الشركة ومعاه لوحة تحكم لإدارة المحتوى من غير كود.

- 🏗️ **الهيرو هو مشهد البناء:** الصفحة بتثبت وإنت بتنزل، والبرج الرئيسي بيتبني دور دور بالرافعة، والأبراج اللي حواليه بتطلع من الأرض، والعربيات ماشية في الشارع، وفي الآخر الشبابيك وأعمدة الإنارة بتنور. لما البناء يخلص، باقي الموقع بيظهر تحته.
- 🏢 **صفحة لكل مشروع** فيها التفاصيل وبيانات المشروع ونطاق العمل ومعرض صور بعارض (تقليب بالأسهم أو بالسحب على الموبايل).
- 🧭 **مجالات العمل:** كل مجال له وصف وأمثلة على اللي بنقدمه، ومرتبط بمشاريعه.
- 🌐 **عربي + إنجليزي** و 🌗 **داكن + فاتح**.
- 🎨 **الهوية:** كحلي `#0D1B2A`، دهبي `#C89D2A`، رمادي `#8D959E`، فاتح `#E2E6EA`. الخطوط: IBM Plex Sans Arabic للعربي و Montserrat للإنجليزي.
- ⚡ **موقع Static من غير Build**، جاهز للرفع على Vercel على طول.

## 📁 هيكل المشروع

```
/
├── index.html            ← الصفحة الرئيسية
├── project.html          ← صفحة المشروع (بتفتح على /project?p=اسم-المشروع)
├── admin.html            ← لوحة التحكم (بتفتح على /admin)
├── styles.css            ← تصميم الموقع
├── script.js             ← أقسام الصفحة الرئيسية
├── project.js            ← صفحة المشروع ومعرض الصور
├── admin.css / admin.js  ← لوحة التحكم
├── data.json             ← كل المحتوى (نصوص عربي/إنجليزي، مشاريع، صور، ألوان...)
├── js/
│   ├── config.js         ← إعدادات التشغيل (مصدر البيانات + كلمة مرور اللوحة)
│   ├── store.js          ← طبقة البيانات (localStorage دلوقتي، API بعدين)
│   ├── site-core.js      ← الأجزاء المشتركة بين الصفحات (الهيدر، الفوتر، اللغة، الثيم)
│   ├── scene.js          ← مشهد المدينة والبناء
│   ├── i18n.js           ← نصوص الواجهة الثابتة + الخطوط
│   └── icons.js          ← الأيقونات
├── assets/
│   ├── brand/            ← ملف اللوجو الأصلي
│   ├── icons/            ← favicon وأيقونات الموبايل
│   └── images/           ← اللوجو المعالج + صور المشاريع والمعرض
├── docs/api-example/     ← مثال API جاهز لقاعدة بيانات (مش بيترفع مع الموقع)
├── vercel.json
├── .vercelignore / .gitignore / .env.example
```

> **ليه `assets/` مش `public/assets/`؟** لما Vercel يلاقي فولدر اسمه `public` في مشروع Static بيعتبره فولدر النشر وبيتجاهل `index.html` اللي برّه.

## 💻 التشغيل على جهازك

```bash
npx serve .
```

وافتح `http://localhost:3000` للموقع، و`http://localhost:3000/admin` للوحة التحكم.

> لازم `npx serve` (مش دبل كليك على الملف) عشان المتصفح يقدر يقرا `data.json`، وعشان روابط زي `/project` و`/admin` تشتغل زي Vercel بالظبط.

---

## 🚀 الرفع على Vercel

1. ادخل [vercel.com](https://vercel.com) بحساب GitHub.
2. **Add New… → Project** ← اختار الـ Repo `Eldeeb` ← **Import**.
3. الإعدادات:

| الإعداد | القيمة |
|---|---|
| Framework Preset | **Other** |
| Root Directory | `./` |
| Build Command | فاضي |
| Output Directory | فاضي |
| Environment Variables | مش محتاج حاجة دلوقتي |

4. **Deploy** ✅

### التحديث (Redeploy)
أي `git push` على فرع `main` بيعمل نشر جديد تلقائيًا:

```bash
git add .
git commit -m "تحديث المحتوى"
git push
```

أو من Vercel: Deployments ← ⋯ ← **Redeploy**.

## 🛠 لوحة التحكم (`/admin`)

**كلمة المرور الافتراضية: `admin123`**، غيّرها أول ما تدخل من **البيانات والأمان**.

| الجزء | بيعمل إيه |
|---|---|
| ترتيب وإظهار الأقسام | سحب وإفلات + إظهار/إخفاء أي قسم |
| مجالات العمل | إضافة مجال بأيقونة وصورة ووصف وأمثلة |
| المشاريع | الاسم، المجال، الموقع، العميل، المساحة، المدة، الحالة، صورة الغلاف، التفاصيل، نطاق العمل، **معرض الصور** + زرار **معاينة صفحة المشروع** |
| باقي الأقسام | من نحن، الخدمات، الأرقام، آراء العملاء، التواصل |
| الإعدادات العامة | اللوجو، الألوان (داكن/فاتح)، الخطوط، اللغة، بيانات التواصل، السوشيال، SEO |
| البيانات والأمان | تصدير/استيراد `data.json`، الرجوع للافتراضي، كلمة المرور |

- كل نص له خانة **عربي** وخانة **إنجليزي**.
- رابط صفحة المشروع بيتعمل تلقائيًا من الاسم الإنجليزي (تقدر تغيّره).
- الصور اللي بترفعها بتتضغط وتتحول **WebP** تلقائيًا.

### ⚠️ إزاي التعديلات توصل لكل الزوار؟
التعديلات من غير باك إند بتتحفظ في **متصفحك إنت بس**. عشان تنشرها:
1. اللوحة ← **البيانات والأمان** ← **تصدير data.json**.
2. حط الملف مكان `data.json` في المشروع واعمل push.

> 💡 للصور الكتير (معارض المشاريع): ارفع الصور في `assets/images/projects/` واكتب مسارها في اللوحة بدل الرفع المباشر، عشان `data.json` يفضل خفيف.

## 🖼 الصور واللوجو

- اللوجو الأصلي في `assets/brand/EL_DEEB_logo.png`. النسخ المستخدمة في الموقع اتقصت واتشالت خلفيتها وبقت شفافة:
  - `assets/images/logo-mark.webp`: الشعار (في الهيدر وشاشة التحميل).
  - `assets/images/logo-full.webp`: اللوجو الكامل (في الفوتر).
  - في الوضع الفاتح، الشعار بيظهر جوه مربع كحلي زي نسخة الكروت في الهوية.
- **صور المشاريع الحالية رسومات مؤقتة (SVG).** استبدلها بصور حقيقية بصيغة WebP بعرض حوالي 1600px (تقدر تحوّلها من [squoosh.app](https://squoosh.app)).

## 🗄 ربط قاعدة بيانات لاحقًا (اختياري)

1. انسخ `docs/api-example/content.js` إلى `api/content.js`.
2. اعمل `package.json` في الجذر:
   ```json
   { "private": true, "dependencies": { "@upstash/redis": "^1.34.0" } }
   ```
3. من Vercel: **Storage → Upstash (Redis) → Connect**.
4. ضيف متغير `ADMIN_TOKEN` (هيبقى هو كلمة مرور اللوحة).
5. في `js/config.js` غيّر `dataSource: 'api'` واعمل push.

| المتغير | إمتى | الوصف |
|---|---|---|
| (مفيش) | الوضع الحالي | مش محتاج أي متغيرات |
| `ADMIN_TOKEN` | وضع الـ API | كلمة مرور اللوحة |
| `KV_REST_API_URL` / `KV_REST_API_TOKEN` | وضع الـ API | بيتضافوا تلقائيًا مع Upstash |

**إضافتها:** Vercel ← Settings ← Environment Variables ← Save ← Redeploy.
